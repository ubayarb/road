Гол user flow

① Дугуй хагарлаа — ROAD-ийн шилдэг жишээ

🆘 SOS→Дугуй хагарсан→Зөвлөгөө «Нөхөх 7 алхам»→чадахгүй→Ойрын дугуй засвар 3.2 км→Захиалах→QPay→Зам заах→⭐ Үнэлгээ

Нэг үйл явдал дотор SAFETY → COMMUNITY → COMMERCE → PAYMENT бүгд ажиллана. Энэ бол ROAD-ийн ялгарал.

② Зам дагуух урьдчилсан захиалга

Чиглэл ТТ→ГС→«Цогтцэций 142 км»→Ундрага дэлгүүр→Бараа сонгох→«Би 18:30-д ирнэ»→Төлбөр→Бизнес бэлдэнэ→5 км-т geofence push→Авах код→⭐

③ Дараалал

Нүүр widget «Гашуунсухайт ~4ц 20м»→Дэлгэрэнгүй→«Би дараалалд орлоо»→Хүлээж байхад: цайны газар, халуун ус санал болгох→Гарахад хүлээлт автоматаар тооцогдоно

Crowdsource loop: хэрэглэгч мэдээлэл өгснөөр бусдын мэдээлэл сайжирна → өдөр бүр нээх шалтгаан.

④ Бэлэглэнэ

Зар оруулах (зураг, тайлбар, байршил)→Хүсэлтүүд→Эзэмшигч сонгоно→Уулзалт→Олгосон→Талархал

⑤ Төлбөр (техникийн)

Order created→Invoice (QPay API)→QR / deeplink→Хэрэглэгч төлнө→Callback→Backend verify→Order = PAID→eBarimt→Push бизнес рүү→Settlement

Callback дангаараа хангалтгүй — заавал provider API-аар баталгаажуулна. Idempotency key-ээр давхар төлбөрөөс хамгаална.

Админ веб

Хөгжүүлэгчид өгөх админ вебийн цэсний бүтэн жагсаалт.

Технологи / архитектур

Замын 60–70% нь сүлжээ муутай, өвөл −35°, дата үнэтэй. Архитектур энэ бодит нөхцөлд захирагдана.

Offline-first

Local DB (SQLite/Realm), sync queue, «сүүлд шинэчлэгдсэн» цаг, оффлайнд ажиллах хэсгийг тодруулах.

Дата хэмнэлт

Зургийн 3 хэмжээ, WebP, lazy load, «хөнгөн горим» тохиргоо.

Push + SMS fallback

Захиалга бэлэн, SOS зэрэг чухал мэдэгдлийг интернэтгүй үед SMS-ээр.

Geo-index

PostGIS / geohash. Бизнес, бэлэг, SOS, ШТС бүгд нэг geo давхаргад.

Route model

Route → Segment → POI(km). «Зам дагуух» бүх функцийн суурь.

Geofence engine

Радиус + чиглэлийн дагуух trigger, батерей хэмнэсэн background location.

Payment abstraction

PaymentProvider interface → QPay эхний. MonPay/PASS/карт нэмэх боломжтой. Secret зөвхөн backend.

Idempotency

Захиалга/төлбөрт idempotency key — давхар төлбөрөөс хамгаална.

Trust & Safety

Report → queue → модератор → шийдвэр → audit log. Бэлэглэнэ дотор далд худалдааг автоматаар илрүүлэх.

CMS

Зөвлөгөө, ангилал, баннер, албан мэдэгдэл — код өөрчлөхгүйгээр удирдана.

Analytics

Event schema эхнээс нь: search, order_created, payment_succeeded, advice_helpful, sos_created, queue_reported.

Feature flag

Функцийг бүсээр/хувиар нээх — pilot-д чухал.

Аюулгүй байдал

JWT + refresh, rate limit, RBAC, plaintext хадгалахгүй, audit log, backup + сэргээх сургуулилт.

Хүртээмж

Том товч, өндөр контраст, нэг гараар — жолооч машин дотор ашиглана.
